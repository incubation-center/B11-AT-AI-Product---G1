# Pinecone TypeScript/Node.js SDK Guide

> **Prerequisites**: See [PINECONE.md](./PINECONE.md) for universal concepts and setup.

This guide provides TypeScript/Node.js-specific patterns, examples, and best practices for the Pinecone SDK.

## Installation & Setup

```bash
npm install @pinecone-database/pinecone
```

Use `.env` for `PINECONE_API_KEY`. See [PINECONE-quickstart.md](./PINECONE-quickstart.md) and [.agents/PINECONE.md](./PINECONE.md) for full setup, quick test, search, RAG, and recommendations. Full TypeScript reference: [pinecone-agents-ref PINECONE-typescript.md](https://github.com/pinecone-io/pinecone-agents-ref/blob/main/.agents/PINECONE-typescript.md).
